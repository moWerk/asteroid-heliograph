# asteroid-heliograph custom messages
#
# Add your own messages to any category below.
# Lines starting with # are ignored.
#
# To add a message to an existing category, use:
#   social: I love you
#   fun: Send nodes
#   emergency: Call my mum
#   navigation: Follow the dog
#
# To create your own Custom category (appears as first category in the app):
#   custom: You are breathtaking
#   custom: Deploy to prod on Friday
#
# This file is an example. To use it, copy it to the app's data directory:
#   SailfishOS 4 and later: ~/.local/share/net.mowerk/harbour-asteroid-heliograph/custom.txt
#   SailfishOS 3:           ~/.local/share/harbour-asteroid-heliograph/harbour-asteroid-heliograph/custom.txt
#
# Messages you type in the app (the + below the messages) are not written
# here; the app keeps them itself and its - removes them. Lines from this
# file can only be removed by editing the file.
#
# Changes made in this file take effect on next app launch.
